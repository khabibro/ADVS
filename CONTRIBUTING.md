# Contributing

Use small pull requests with focused tests. Do not commit secrets, real administrative documents, or raw OCR output containing personal information.

Suggested commit sequence:
1. chore: initialize monorepo
2. feat: add FastAPI backend and database
3. feat: add Next.js frontend
4. feat: add document upload pipeline
5. feat: add OCR provider abstraction
6. feat: add document classification and extraction
7. feat: add validation engine
8. feat: add project dashboard
9. test: add backend and integration tests
10. docs: add project documentation and roadmap
