# Project Overview

ADVS supports a first-stage MVP for administrative document verification. Users create a project/checklist, upload documents, process direct PDF text or OCR text, classify one of four MVP document types, extract fields, and validate against deterministic rules.

MVP boundary: no OCR training, no paid LLM requirement, no production auth, no object storage, no background queue. The codebase is structured so those can be added later.

Primary users are university project members, industry reviewers at Flash21, and demo operators.

Questions to Confirm with Flash21 are listed in `docs/archive/ROADMAP.md`.
