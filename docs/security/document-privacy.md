# Security and Privacy

Administrative documents may contain personal and corporate information. MVP safeguards include environment-based secrets, safe filename handling, upload type and size validation, SQLAlchemy ORM, CORS configuration, controlled local storage, no arbitrary file serving, and no full OCR text or secrets in logs.

Production gaps: authentication, role-based access control, encryption at rest, retention/deletion policy, consent/privacy policy, secure cloud configuration, auditability, formal personal-information handling review, monitoring, and backup/recovery.

Cloud OCR must be approved by Flash21 and the university before real personal documents are processed.
