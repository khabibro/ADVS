# Midterm materials

This folder contains earlier presentation milestones and the current UCWIT 2026 paper source. Build the next deck from `paper/`, `RESULTS_CURRENT.md`, and `ACCURACY_CHECK.md`. Treat the older decks and demo assets as historical records.

## Current sources

- `paper/`: the four v2 paper files (review and final PDF/DOCX) plus `PAPER_SUMMARY.md`, a short slide-ready summary. The final files include author information.
- `RESULTS_CURRENT.md`: current paper and final-results numbers, cohort splits, safety results, and development-step comparisons.
- `ACCURACY_CHECK.md`: comparison of the old midterm source files with the current paper and final-results ledger.

## Historical material

- `RESULTS.md` and `metrics.csv`: interim October results and metrics.
- `slides_sources.md`: sources for the earlier midterm deck.
- `ROADMAP.md`: earlier milestone roadmap.
- `ARCHITECTURE_SUMMARY.md`: earlier implementation-oriented pipeline summary.
- `DEMO_SCRIPT.md`, `DEMO_SCRIPT_v1.md`, `DEMO_SCRIPT_v2.md`: scripts for older software demos; verify the live application before reuse.
- `v4/`: earlier deck, source notes, build report, builder, and captures. Preserve as a milestone archive.
- `screenshots/`, `screenshots_v2/`, `screenshots_v3/`: screenshots from earlier demo builds.
- `ADVS_midterm.pptx` and `ADVS_midterm.pdf`: previous midterm deck outputs.

## Public repository note

These files are tracked or may become trackable in a public repository. The review files are anonymized according to the requested text scan. The final paper PDF and DOCX contain author names, affiliations, and acknowledgments. Before publishing a commit, decide whether the full author-version files should be public; consider adding `docs/midterm/paper/` to `.gitignore` and keeping the full paper in private storage if not.
